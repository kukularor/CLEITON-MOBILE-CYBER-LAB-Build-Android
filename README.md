# CLEITON MOBILE CYBER LAB — Build Android

Repositório para compilar o aplicativo Android.

## Preparação
Baixe o pacote `CLEITON_MOBILE_CYBER_LAB_PRONTO_PARA_COMPILAR.zip` fornecido no ChatGPT. Extraia-o e envie **o conteúdo interno** da pasta `CLEITON_CYBER_GUARDIAN/` para a raiz deste repositório (não envie só o ZIP). Mantenha o workflow em `.github/workflows/build-apk.yml`.

Depois, abra **Actions → Compilar CLEITON MOBILE CYBER LAB APK → Run workflow**. Após sucesso, abra a execução e baixe o artefato `CLEITON_MOBILE_CYBER_LAB_debug_APK`.

O APK é uma versão de testes, não uma versão de distribuição pública. O catálogo NetHunter não executa automaticamente ferramentas externas.
